MSABA SMART DISPLAY V4.2 AUTO KIOSK
Dibina daripada V4.1 yang telah berjaya.

BARU:
- Offline screen automatik.
- Auto reconnect bila Internet kembali.
- Recovery check 30 saat.
- Screen Wake Lock jika disokong.
- Windows startup launcher.

GITHUB: replace index.html, manifest.json, service-worker.js, offline.html, icon-192.png, icon-512.png di root dan Commit.
Code.gs tidak perlu diubah lagi.

WINDOWS AUTO START:
Win+R > shell:startup > copy START-MSABA-DISPLAY.bat ke folder itu > restart PC.
Untuk display tetap, set Windows Screen/Sleep kepada Never juga.
